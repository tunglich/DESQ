# DQN market-timing on DES-model output

Deep Q-Network (1D-CNN, `<DES> + <OHLC>` features, `Skip / Buy / Close`
actions) applied to the TW-50 universe, adapted from
[tunglich/Market-Timing-DQN](https://github.com/tunglich/Market-Timing-DQN).

## What changed vs the reference repo

1. **`<DES>` feature source.** The reference repo's `<DES>` was a binary
   label derived from **ground-truth** forward-return direction (i.e. it
   leaked the answer). This variant substitutes the DES pipeline output:

       <DES> = 1  if  prob_up > threshold  else 0

   where `prob_up` is the KNORA-E aggregated probability produced by
   `../tw50_des.py` at the end of the DESQ Stage 3.

2. **No per-symbol accuracy `window`.** The reference repo shipped four
   accuracy settings per stock (`55 / 60 / 65 / 75`) and emitted one CSV
   per (symbol, window). DESQ produces exactly one DES signal per stock, so
   the `window` concept doesn't apply and has been removed from
   `build_dqn_data.py`, `walk_forward.py`, `train_dqn.py`, and
   `backtest.py`. Everything else in the DQN pipeline is unchanged.

## Prerequisites

1. Run the DESQ pipeline first so that DES predictions exist under
   `../artifacts/des/pred/DES_<sym>.csv`:

   ```powershell
   cd ..
   python tw50_flood.py  --top50 --aspect all
   python tw50_dflood.py --top50 --aspect all
   python tw50_des.py    --top50
   ```

2. Supply your own OHLCV files under `../prices/<sym>.csv` with columns
   `Date, Open, High, Low, Close, Volume`.

## Install

Python 3.10+ (tested on 3.11).

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

For GPU training install the matching CUDA build of PyTorch first.

## Usage

### 1. Build the DQN input CSVs from the DES pipeline output

```powershell
python build_dqn_data.py --top50 --overwrite
```

This writes one `data/<sym>_all.csv` per stock.

### 2. Train one symbol with 5-fold walk-forward

```powershell
python src/train_dqn.py --symbol 2330 --fold all --hours 1.5
```

### 3. Backtest on the held-out test window

```powershell
python src/backtest.py --symbol 2330
python src/backtest.py --all --out backtest_summary.csv
```

## Coverage note

`tw50_des.py` currently predicts on the test window only
(`2024-01-01 .. 2026-03-31`). The reference DQN did 5-fold walk-forward on
`2005-01 .. 2023-12` pre-test history, which is **not** available here.
Either:

- Extend `../tw50_dflood.py` to also emit in-sample DES predictions for the
  training years, then rerun `build_dqn_data.py`; or
- Shorten the DQN training regime to run entirely inside the test window
  and treat the results as a diagnostic rather than an out-of-sample study.

## Data schema

| Column   | Meaning                                                                     |
|----------|-----------------------------------------------------------------------------|
| `<DATE>` | `YYYY-MM-DD` trading day. Ignored by `lib.data`.                            |
| `<DES>`  | Binary DES signal derived from `tw50_des.py` KNORA-E probability (`{0,1}`). |
| `<OPEN>` | Session open price.                                                         |
| `<HIGH>` | Session high.                                                               |
| `<LOW>`  | Session low.                                                                |
| `<CLOSE>`| Session close.                                                              |

`lib.data.load_relative` normalises OHLC to open-relative returns and
stacks them with `<DES>` along the channel axis before the CNN.
