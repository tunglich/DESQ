# DRL 520-observation evaluation

These artifacts are generated by the development DRL simulator with `--observations 520`. Every curve contains exactly 520 common daily return observations and is rebased at the preceding close.

| Evaluation | Window | DRL all_75 | Benchmark |
| --- | --- | ---: | ---: |
| TSMC (2330.TT) | 2024-01-30 to 2026-03-31 | 232.93% | 176.21% |
| MediaTek (2454.TT) | 2024-01-30 to 2026-03-31 | 269.17% | 65.76% |
| TWSE Top-50, market weighted | 2024-01-19 to 2026-03-31 | 167.98% | 94.76% |

The portfolio result covers all 50 constituents. Simulation uses the all_75 checkpoints, 10-bar state history, seed 42 for both epsilon selection and random action sampling, epsilon 0.01, 0.10% buy cost, and 0.34% sell cost. The stock benchmark is buy and hold; the portfolio benchmark is TWA02.

The CSV files are the numerical source for the displayed values and the PNG files are generated views. Checkpoints remain in the development archive, so these curves support result inspection but do not make a clean-room rerun possible from this repository alone.
